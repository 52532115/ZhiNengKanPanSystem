# 观澜 · A 股与 ETF 研究台

一个零第三方依赖的本地 A 股与 ETF 行情分析程序。它读取公开的日线行情，把「现在什么状态」「在池子里排第几」「该给多少总暴露」拆成三个互不替代的字段（描述 / 选股 / 择时），每个字段有自己的参照系和验证口径；页面上**没有综合评分**，也不存在「评分 75+ 所以看多」这类跨口径推断。

## 运行

需要 Python 3.10 或更高版本，并确保电脑可以访问公开行情服务。

```powershell
python app.py
```

然后打开 <http://127.0.0.1:8000>。也可以双击 `启动观澜.cmd`。

## 功能

- 支持沪深京 A 股，以及沪深交易所 ETF/场内基金六位代码；
- 代码 / 名称 / 拼音缩写联想搜索，对接东方财富 suggest 接口，输入「茅台」「gzmt」也能解析到 600519；
- 自动识别 `510300`、`588000`、`159915`、`518880` 等 ETF，使用三位价格精度与基金指标展示；
- 20/60/120 日均线、MACD、RSI、量比、年化波动率、最大回撤；
- K 线蜡烛图（使用开盘/最高/最低/收盘），副图可在成交量 / MACD / RSI 之间切换，支持在图上拖动框选区间放大、双击还原；
- 相对强弱：个股与沪深 300 归一化到 100 后同图对比，给出 RS 比率曲线与 20 日超额收益；**RS 只用于展示与对照，不进入任何评分**（v3 综合分已下线）；
- 自选股组合面板：服务端并发批量取回价格、涨跌幅与三字段，**池内分位由整张自选表一起算**，按池内分位排序并把客观异动置顶，上限 20 只；
- 分析标的写入 URL，浏览器前进/后退可在历史标的间切换；
- 沪深 300 走势 + 市场宽度合成市场 regime，只输出三档状态与总暴露上限；
- 趋势状态给「同类分位 / 相对自身近 60 日分位 + 五档标签 + 六个分量的 0–100 刻度」，每个字段下方挂验证结论（通过 / 未通过及原因）；
- 浏览器本地保存自选股；
- 5 分钟历史行情缓存和 20 秒快照缓存；
- 不需要安装 Flask、pandas 或数据库。

| 方法 | 路径 | 说明 |

## 评分有效性验证（walk-forward）——历史章节

> **历史说明**：本节记录的是已下线的「单一综合分」v1→v3 时代。前端现在只有三字段口径
> （描述 / 选股 / 择时），`analyze()` 不再输出总分，页面也不再展示「评分构成」。
> `analyzer.score_factors()` 与 v3 权重仅保留给 `walkforward.py` / `xsec.py` 做旧口径回放与对照，
> 下面的 IC 结论因此只说明"那一版分数"的表现，**不代表当前三字段的验证结论**——
> 三字段的结论见 [三字段口径](#三字段口径fields-py--etf_allocation-py--validate_fields-py)。

评分权重最初是手调的，`walkforward.py` 用历史数据把它们变成可检验的：

```powershell
# 首次运行会拉取行情并缓存到 .cache/walkforward
python walkforward.py
# 只读缓存、不联网复跑（可复现）
python walkforward.py --offline
# 步长 5 抽样，降低重叠窗口影响，做稳健性复核
python walkforward.py --stride 5 --outdir reports/robust_stride5
# 更换超额收益基准（默认沪深300）
python walkforward.py --benchmark 000905
# 扩样本：沪深300 成分股按市值等距抽样 60 只
python walkforward.py --universe hs300 --max-symbols 60 --outdir reports/hs300_60
# 用初始权重复跑，做版本对照（默认已是 v3）
python walkforward.py --weights v1 --outdir reports/legacy_v1
```

规则：对每个历史交易日，只用 `rows[:t+1]` 调用一次 `analyze()` 打分，未来 5 / 20 / 60 日收益在评分之后单独计算，不回流到入参，因此不存在未来数据泄露（`tests/test_walkforward.py` 用「截断尾部后历史评分必须不变」覆盖该点）。

报告同时给出两套口径：绝对收益，以及「个股收益 − 同期沪深 300 收益」的超额收益。后者用于剥离 beta 和普涨——单边行情里所有分桶都涨，并不代表评分有排序能力。

### 权重档案 v1 → v3

`score_factors()` 内置三套权重，默认 `v3`。v2 是按 20 日超额收益的单因子 edge 重估的结果，v3 在 v2 基础上加入相对强弱因子：

| 因子 | v1 | v2 | v3 | 8 只样本超额 edge（20 日） |
| --- | --- | --- | --- | ---: |
| 价格 vs MA20 | +9 / −9 | +8 / −8 | +8 / −8 | +0.86% |
| MA20 vs MA60 | +9 / −7 | +3 / −3 | +3 / −3 | +0.08% |
| 价格 vs MA120 | +6 / −6 | +5 / −5 | +5 / −5 | +0.86% |
| 相对强弱（20 日） | — | — | +6 / −6 | +2.21% |
| MACD 柱与斜率 | +8 / −7 | +9 / −8 | +9 / −8 | +1.13% |
| RSI 区间 | +7 / −6 / −4 | +3 / −3 / −2 | +3 / −3 / −2 | −0.33% |
| 近 20 日涨幅 | +5 / −6 / −3 | +3 / −4 / −2 | +3 / −4 / −2 | +0.78% |
| 量比 + 当日涨跌 | +4 / −5 | +3 / −3 | +3 / −3 | +0.61% |
| 年化波动率 | +4 / −8 | +5 / −9 | +5 / −9 | +2.13% |
| 近 120 日回撤 | −6 | −7 | −7 | +0.40% |

相对强弱因子用 20 日超额收益触发：跑赢基准 3% 以上加 6 分，跑输 3% 以上扣 6 分，中间记 0 分。基准行情由数据层注入，`analyze()` 本身仍然只做纯计算；取不到基准时该因子记 0 分，不影响其他因子。

同一批 8 只样本内的 v1 → v2 变化：20 日绝对 IC `0.053 → 0.085`，20 日超额 IC `0.096 → 0.114`，5 日超额 IC `0.074 → 0.078`（t 值 `1.91 → 2.00`），最高分桶 20 日超额 `+1.16% → +1.72%`，分标的 20 日 IC 为正的只数 `3/8 → 5/8`，「偏积极」分桶占比 `38.7% → 25.1%`。

加入 RS 后的 v3（同样 8 只）：20 日绝对 IC `0.085 → 0.097`，20 日超额 IC `0.114 → 0.127`，5 日超额 IC `0.078 → 0.085`（t 值 `2.00 → 2.19`）；60 日超额 IC 从 `0.059` 回落到 `0.047`。RS 因子在这 8 只样本上的 20 日超额 edge 为 **+2.21%**，扩样本后降到 +0.36%。

### 扩样本复核：结论反转

把股票池换成沪深300 成分股按市值等距抽样的 60 只，共 24,497 个评估点：

| 口径 | 5 日 | 20 日 | 60 日 |
| --- | ---: | ---: | ---: |
| 绝对 IC（v3） | −0.019 | −0.047 | −0.058 |
| 超额 IC（v3） | −0.011 | −0.038 | −0.086 |
| 绝对 IC（v2） | −0.020 | −0.046 | −0.055 |
| 超额 IC（v2） | −0.010 | −0.036 | −0.084 |

分标的 20 日 IC 只有 16/60 为正（60 日 10/60）；单因子超额 edge 也反转：近 120 日回撤 **−3.18%**、近 20 日涨幅 **−2.77%**、年化波动率 **−3.00%**，只有 MACD、量比和 RS 略微为正。

这说明 8 只样本的正 IC 主要来自样本结构（4 只 ETF + 4 只大市值股，且区间内黄金 ETF 等单边上涨），不能外推。当前评分在更宽的股票池上没有排序能力，更接近「趋势状态描述」而非收益预测。

横截面口径（每天只在当日有评分的标的之间排序）给出同样结论：

| 样本 | 5 日 | 20 日 | 60 日 |
| --- | ---: | ---: | ---: |
| 8 只 | +0.083 | +0.152 | +0.055 |
| 60 只 | −0.008 | −0.041 | −0.072 |

60 只样本里，20 日横截面 IC 只有 42.1% 的交易日为正，60 日只有 30.4%。所以问题不在「合并样本口径」——即使每天只在股票之间排序，评分也没有稳定的选股能力。

因此 v2/v3 的权重不再继续按全样本调参——那只会对 2024–2026 这一段行情过拟合。报告保留为正反两组证据，供后续做分 regime 建模时对照。

输出到 `reports/`：

| 文件 | 用途 |
| --- | --- |
| `walkforward_table.html` | 自带作用域样式的表格片段，可直接粘进 `index.html` 的 methodology 区块 |
| `walkforward_preview.html` | 套上项目色板的独立预览页 |
| `walkforward.md` | 便于审阅和归档的 Markdown 版 |
| `walkforward.json` | 机器可读结果，含分位数分组、超额收益与单因子归因明细 |

评分规则只有 `analyzer.score_factors()` 一个事实来源：前端「评分构成」面板、`analyze()` 的总分与判断依据、walkforward 的单因子归因都复用它，不再维护第二份复刻逻辑。

另外会按标的分别复核：把不同标的混在一起统计时，合并样本的正相关可能只反映品种间差异，报告会显式标注「合并口径」与「分标的」的背离，并给出五等分交叉验证，避免用一张表就下结论。

## 横截面分位模型与净值回测（`xsec.py`）

walk-forward 的口径是「绝对分数 → 未来绝对收益」，样本按标的合并，混入了品种间差异。`xsec.py` 换成标准的多因子横截面流程，并把结论落到净值上：

```powershell
# 沪深300 抽样 60 只，默认 20 日标签、5 日调仓、Top 20%、单次换手 ≤40%
python xsec.py --offline
# 换股票池 / 周期 / 调仓节奏
python xsec.py --offline --universe hs300 --max-symbols 60 --horizon 10 --rebalance 10
python xsec.py --offline --top 0.1 --turnover 0.2 --outdir reports/xsec_tight
```

| 环节 | 口径 |
| --- | --- |
| 标签 | 未来 20 日收益按当日横截面排名转分位 `(rank-1)/(n-1)`；当日标的数 < 20 的横截面丢弃 |
| 特征 | MACD 柱、量比、RS 三个因子族；族内连续化表达（如 MACD 柱 vs 柱斜率）只按训练集横截面 IC 选，验证集不参与 |
| 切分 | 按时间顺序前 60% 训练、后 40% 验证；切分点前剔除 20（标签跨度）+ 5（embargo）个交易日 |
| 拟合 | OLS：标签分位 ~ 特征分位，闭式解 + 1e-4 岭项，系数可读作"特征分位每升一档，标签分位平均升多少" |
| 组合 | 当日得分 Top 20% 等权，每 5 个交易日调仓 |
| 成本 | 佣金 2.5bp（双边）、过户费 0.1bp（双边）、印花税 5bp（仅卖出）、滑点 5bp（双边）→ 单边买 7.6bp / 卖 12.6bp |
| 换手 | 单次调仓单边换手上限 40%，超出按比例缩减；未成交的旧仓位继续持有 |
| 基准 | 同一股票池等权、同调仓日再平衡、不计成本 |

验证集（2025-11-26 → 2026-10-21，217 个交易日）结论：

| 组合 | 总收益 | 年化 | 最大回撤 | 年换手 | 成本(bp/年) |
| --- | ---: | ---: | ---: | ---: | ---: |
| 新模型（含成本） | −9.64% | −11.11% | −26.13% | 1984% | 398 |
| 新模型（成本前） | −6.56% | −7.58% | −25.01% | 1986% | 0 |
| 等权基准 | −2.24% | −2.60% | −10.08% | 159% | 0 |
| 旧规则 v3（同成本） | −10.28% | −11.84% | −15.98% | 1877% | 376 |

- 扣成本前后都跑输等权基准，说明亏损主要来自信号而不是摩擦；训练集（2024-07 → 2025-10）曾小幅领先（+56.9% vs +51.8%），验证集反转，属于样本外失效。
- 11 个 20 日窗口只有 4 个超额为正（36.4%）；两段最差窗口各亏 5–7 个百分点。
- 特征层面：训练 IC 三个因子都是弱正（MACD +0.027、量比 +0.022、RS +0.011），验证 IC 全部转负（RS −0.089），与净值结论一致。
- 稳健性：换 67 只全样本（−8.16% vs −3.70%）、换标签周期 5 / 10 日、换换手上限 20%–100%，结论不变。

输出 `reports/xsec/`：`xsec.json`、`xsec.md`、`xsec_table.html`（可粘贴片段）、`xsec_preview.html`（独立预览）。

## 评估协议（`protocol.py` + `evalkit.py` + `execution.py` + `style.py`）

前面的验证有三处硬伤：验证集被反复用于 horizon / universe / 换手上限的稳健性检查，早已不是干净的样本外；IC 只有点估计；信号按当日收盘成交偏乐观，也没有风格基准。`protocol.py` 把评估重做成分层的一组模块：

```powershell
# 完整协议：5 折 purged walk-forward + 末 2 年 lockbox + 自助区间 + 台账
python protocol.py --offline            # 默认 2400 根日线、20 日 horizon、5 折
python protocol.py --offline --folds 6 --horizon 10 --turnover 0.3
# 首次（或换股票池）需要联网把长历史缓存下来
python protocol.py --refresh --max-symbols 60
```

| 模块 | 职责 |
| --- | --- |
| `evalkit.py` | 统计口径：块自助区间、重心化 bootstrap p 值、功效分析、BH-FDR、通货紧缩夏普、试验台账、线性模型版 MDI |
| `execution.py` | 执行口径：收盘出信号、次日开盘成交，涨跌停（10/20/30%）与停牌过滤，T+1 不得卖出当日买入的份额 |
| `style.py` | 风格基准：成交额/换手率反推市值、12-1 动量、收益相关性聚类做行业代理，Fama-MacBeth 把超额拆成风格贡献 + 残差 |
| `protocol.py` | 三目标定义、5 折 purged walk-forward、lockbox、harness 校准、台账汇总、报告渲染 |

### 三个目标各自定标签与指标（`protocol.TARGETS`）

| 目标 | 标签 | 指标 | 通过标准 |
| --- | --- | --- | --- |
| A 描述分 | 未来 20 日波动率 / 最大回撤 / 下行波动 / 5% VaR | 分数与风险标签的横截面 IC + 95% 区间 | 至少一个风险标签的区间不含 0，不要求收益 IC |
| B 选股分 | 次日开盘进场、20 日后开盘出场的横截面分位收益 | IC + 95% 区间 + 扣费净净值（T+1） | IC 区间不含 0 且净净值跑赢同池等权 |
| C 市场 regime | 组合回撤与目标仓位 | 最大回撤改善、年化换手、切换成本 | 回撤改善大于切换成本，且 Calmar 不劣化 |

### 本轮结论（34 只沪深300 抽样、1665 个开发交易日、486 个 lockbox 交易日）

| 目标 | 结果 | 判定 |
| --- | --- | --- |
| B | IC +0.013，95% 区间 [−0.019, +0.047]；净净值 +302.8% vs 等权 +240.7% | 未达标：区间覆盖 0 |
| A | 分数对"未来波动率"IC −0.096，区间 [−0.161, −0.027]（高分对应低风险） | 达标 |
| C | 回撤改善 −1.91pct，Calmar 0.35 vs 0.69，切换成本 71bp/年 | 未达标 |

- **功效**：34 只股票的单日 IC 噪声 σ≈0.26（理论下限 1/√N≈0.17），83 个独立 20 日块只能检出 |IC|≥0.08。要检出 IC=0.03 需要约 260–570 个独立周期（21–47 年），不是 20 个。
- **执行**：同日收盘 +298.7% → T+1 开盘 +302.8%，方向与幅度都不稳定，两个口径必须同时报。
- **风格**：残差 alpha 占超额 66%（t=1.20），市值/动量/行业三项合计贡献并不显著；实际持仓平均 20 只，不是严格 Top 20%。
- **多重检验**：台账 43 条试验，原始 p<0.05 的 0 条，BH-FDR 后 0 条；通货紧缩夏普 DSR=0.79 但门槛 SR0 已被抬高。
- **harness 校准**：20 组 iid 随机信号与 20 组平滑（自相关）随机信号的 95% 区间全部覆盖 0，误报率 0%。
- **抽样敏感性**：股票池从 32 只换到 34 只，超额从 −54pp 变成 +62pp，而两次 IC 区间都覆盖 0——点估计不能当结论。

数据说明：东方财富对批量长历史请求会限流，本轮 60 只抽样里 34 只成功缓存了 2400 根日线（其余 26 只只保留了 600 根的旧缓存）。等限流解除后 `python protocol.py --refresh` 可补齐；报告的 `params.failures` 会如实列出没取到的标的。

输出 `reports/protocol/`：`protocol.json`、`protocol.md`、`protocol_table.html`（可粘贴片段）、`protocol_preview.html`（独立预览）。试验台账落在 `.cache/eval/trials.jsonl`，跨会话累计。

## 股票池重建与池层验证（`research/`）

前面的回测都建立在一个没写出来的假设上：**股票池 = 今天还在的、当年就在指数里的票**。这个假设有两个后果：中途被剔除或退市的标的整段消失（幸存者偏差），字段（行业、ST、停牌、涨跌停、上市天数）靠现算、口径不统一。`research/` 把股票池当成一个需要单独验证的变量，与生产层彻底分开。

| 模块 | 职责 |
| --- | --- |
| `research/manifest.py` | 版本化缓存：每次抓取生成 `pit-YYYYMMDDTHHMM`，登记来源、抓取时间、行数、sha256；`verify()` 能发现文件被改动 |
| `research/bs_source.py` | 唯一 import `baostock` 的地方：PIT 成分（按月快照）、后复权日线（`adjustflag=1`）、`isST`/`tradestatus`/换手率；分段落盘、可断点续跑 |
| `research/clean.py` | 后复权收益、成交量同尺度复权（`amount/close`）、IPO 首日剔除、字段统一与回填、停牌/涨跌停/一字板标记、跨源校验 |

落地方式：`research.universe.prepare_cache()` 把 PIT 面板写成 `.cache/fields/stocks_pit/` + `members.json`，并带版本戳（版本号 + 日线数量），**日线数量变了就自动重建**——否则"抓完新数据却复用旧面板"会让 PIT 重跑悄悄跑在旧样本上（踩过一次：99 只的面板被 494 只的数据复用了）。

已知偏差与限制：

- **覆盖不完整**：494/1405，沪深300 每日 221/300（74%）、中证500 222/500（44%），中证500 层偏薄；
- **小盘层是替代口径**：用成分内自由流通市值后 1/3 近似（全市场小盘股要 4000+ 只日线）；
- **行业分类**用证监会大类（baostock 只有这一套，不是申万/中信）；
- **ST 字段**来自 baostock 的 `isST`，指数成分里 ST 几乎为 0（字段体检均值 0.0 只），所以 ST 过滤对指数池影响可忽略，但对全市场池仍是必需的。

## 降换手与成本控制（`rebalance.py` / `turnover_study.py`）

Top 20% / 5 日调仓的问题是**换手**不是信号：排名在阈值附近抖动，组合整进整出，年换手能到 2548%，单边 20bp 就是 1019bp/年的成本，把 5% 出头的毛超额吃光。

```powershell
python turnover_study.py --offline --cost-bps 20     # 216 组网格 + holdout + 容量
```

| 参数 | 取值 | 作用 |
| --- | --- | --- |
| 进入阈值 | 前 20% | 新进必须排在前 20% |
| 保留阈值 | 前 60% | 老仓只要还在前 60% 就不动（缓冲带 40pp） |
| 最短持有期 | 4 个调仓周期（≈20 个交易日） | 防止刚买就被踢 |
| 分批调仓 | tranche = 1.0（一次到位） | 实测分批只是把持仓摊宽，不加分 |
| 信号平滑 | 5 日 EWMA 分位 | 从信号端抑制排名抖动 |
| 权重 | 等权 | inv_vol / 分数加权都更差（见报告） |

| 指标 | 基线（无 buffer） | 改进方案 | 等权基准 |
| --- | ---: | ---: | ---: |
| 年换手（单边） | 2548% | **740%** | 106% |
| 成本拖累（20bp） | 1019bp/年 | **296bp/年** | 0 |
| 净 Sharpe | 0.313 | **0.886** | 0.922 |
| 年化收益 | 4.85% | **23.91%** | 20.46% |
| 最大回撤 | −54.2% | −34.8% | −29.3% |
| 相邻持仓 Jaccard | 0.341 | 0.786 | — |

- **换手—净 Sharpe 前沿**：216 组里 144 组满足换手 < 800%；把换手从 1200% 压到 600% 附近净 Sharpe 不降反升（砍掉的是噪声交易），再往下压才开始伤收益。
- **buffer 前后 IC**：0.0332 → 0.0288，降幅 **0.00447**（上限 0.005）。buffer 冻结了持仓评分，这个降幅就是省换手的真实代价。
- **成本敏感性**：10bp → 0.937、20bp → 0.886、30bp → 0.836；**在 10bp 下净 Sharpe 达标（≥ 0.922），20bp 下差 0.036**。
- **容量**（参与率 ≤ 10%）：当前池 p10 约 2.6 亿、中位 68 亿；中小盘情形（成交额 ×0.3）p10 约 0.77 亿。
- **选股 vs 再平衡**：改进方案 567% vs 买入持有首期组合 104% vs 等权 419%，说明这套高换手策略的收益主要来自再平衡而不是选股——这也是为什么降换手之后收益没有崩。
- **未采用**：inv_vol（0.718）、波动目标仓位（0.878，仅开发折有效）、扩到 Top 30%（0.871）。

### 通过标准：3 项中 2 项达标

| 标准 | 实测 | 判定 |
| --- | ---: | --- |
| 年换手 < 800% | 739.8% | 通过 |
| 20bp 净 Sharpe ≥ 等权 | 0.886 vs 0.922 | **未通过（差 0.036）** |
| buffer 前后 IC 降幅 < 0.005 | 0.00447 | 通过 |
| holdout 净 Sharpe ≥ 基线 80% | 0.477 vs 0.202 | 通过 |

差口的来源是**宽度**：改进方案只持 6 只，等权持 34 只，波动结构不同。扩到 Top 30%（9 只）没有改善（0.871），inv_vol 与波动目标也都不稳定。要真正达标，只有两条路——把单边成本压到 10bp 以内，或把池子扩到 100 只以上让持仓数上去。**在 20bp 与 34 只样本下，"年换手 < 800% 且净 Sharpe ≥ 等权"这一组约束无法同时满足**，这是数据给的结论，不是参数没调够。

## 三字段口径（`fields.py` / `etf_allocation.py` / `validate_fields.py`）

### 为什么要拆

原来的单一 0–100 分同时承担三件事：描述"现在什么状态"、给选股排序、暗示仓位。所有跨口径推断都长得像结论——"评分 75+ 所以看多"其实就是把描述当择时用。现在三个字段各有各的参照系：

| 字段 | 用途 | 参照系 | 通过与否看什么 |
|---|---|---|---|
| `descriptor` 趋势状态 | 描述 | 同类资产（个股 / ETF）的历史分数分布 | 对风险标签的秩相关 |
| `selection` 横截面分位 | 选股 | 当日同池横截面 | 锁箱期 IC 区间下限 |
| `regime` 市场状态 | 择时 | 基准自身近三年标准化分数 | 组合回撤是否改善 |

`fields.assert_use()` 在代码层拒绝跨用途调用（`assert_use("descriptor", "timing")` 直接抛错），前端每个字段单独标注口径并挂自己的验证结论。

### 阈值改为分位

绝对阈值（75/60/45/30）全部下线。档位只看百分位切点 20/40/60/80，分数本身不再参与判断。资产类别改变的是「多少分对应多少分位」这张映射表：

```
python validate_fields.py --offline   # 重新校准，只用锁箱期之前的数据
```

校准结果写在 `reports/fields/calibration.json`，`fields.py` 内置表兜底；个股 P50 分数 50.9、ETF 52.8，同一分数在 ETF 上通常对应更高分位（ETF 波动更低、分布更窄）。指数（沪深300 / 中证500 / 中证1000）只有三条序列、构不成同类分布，因此**不并进 ETF 校准类**：`asset_class_of('index') == 'index'` 且该类没有 knots，`describe()` 会关闭同类分位、档位改用「相对自身」分位并在 `band.basis` 上标明 `self`。可选两种分位口径：**同类历史分位**（主）与**相对自身近 60 日分位**（辅），自选池里还会并列给出**当日同池分位**，三者不混用。

### 独立验证结果（60 只个股 × 3110 根日线；8 只跨资产 ETF）

| 字段 | 核心指标 | 数值 | 判定 |
|---|---|---|---|
| 趋势状态 | 未来 20 日波动的同期池化 Spearman | −0.27（逐标的 −0.29） | 未通过（差 0.03） |
| 横截面分位 | 锁箱期 IC（2024-07 起） | +0.025 [−0.026, +0.084] | 未通过 |
| 市场 regime | 最大回撤改善 | 13.36pp（−32.1% vs −45.5%） | 通过 |
| 跨资产配置 | 净 Sharpe / 最大回撤 | 0.818 / −11.7%（等权 0.351 / −36.3%） | 通过 |

三条值得记住的细节：

1. **描述分的第一版是无效的**。原设计「趋势 0.60 + 风险 0.40」且含 12–1 动量，归因发现动量分量与未来波动**正相关**（ρ≈+0.29，趋势越强未来波动越大），把风险分量的负相关抵消掉，合成后 ρ≈−0.02。移除动量、把风险分量提到 0.75 后才回到 −0.29。报告把这次改动标为「同一数据上的第二次尝试」，没有假装它是先验设计。
2. **描述分的分位桶是完美单调的**（ρ=−1.0），但对最大回撤的区分力明显弱于波动（−0.19 vs −0.29），且 2018H1 半年反向（低波动之后波动率跳升）。所以它只能当「当前状态的单调刻度」，不能当风险预测。
3. **选股分没有证据**。锁箱期 IC 区间覆盖 0，扣费后 Sharpe 0.71 反而低于同池等权 0.96。这与 `xsec.py` 的结论一致：把时间序列趋势因子拿去做横截面排序，口径本来就不对。

### 跨资产 ETF：引擎已统一到 `etf_allocation`

这一节原先记录的是 `crossasset.py` 那套（7 条腿、逆波动、回撤减半、成本 7.6/12.6bp）。
它与 `etf_allocation.py`（12 条腿、ERC、MA60/MA120 非对称、成本 7.5/7.5bp）是**同一件事的两套实现**，
导致 `validate_fields` 验的配置和页面展示的配置不是同一个东西。

## 新因子族（`factors.py` / `factor_study.py`）

现有三族（MACD 柱、量比、RS20）全是趋势/动量类，彼此并不独立：MACD 柱与 RS20 相关 0.53、
RS20 与 RS60 相关 0.45，RS 的 OLS 系数只有 −0.003。补五族共 20 个纯 OHLCV 因子，全部因果、
只用标准库。

### 因子清单

| 族 | 因子 | 定义 | 先验 |
|---|---|---|---|
| 反转 | 5 日反转 / 1 日反转 / 隔夜跳空 | −(c_t/c_{t−5}−1) / −(c_t/c_{t−1}−1) / −mean₅(o_t/c_{t−1}−1) | + |
| 动量 | 12–1 / 6–1 / 52 周高点 / 斜率×R² / 加速度 | c_{t−21}/c_{t−252}−1、c_{t−21}/c_{t−126}−1、c_t/max(high₂₅₂)、60 日 log 价格回归斜率×R²、近 21 日收益减前 21 日收益 | + |
| 风险 | 特质波动 / beta / 下行波动 / 回撤 / 偏度 / 峰度 | 60 日对市场回归残差σ、120 日 beta、√mean(min(r,0)²)、60 日回撤深度、60 日三阶/四阶矩 | 波动与 beta、回撤、峰度为 −，偏度为 + |
| 流动性 | Amihud / 换手率 / 量价背离 | mean(abs(r)/成交额亿元)、mean(turnover)、corr(Δlog volume, r) | 非流动性 +，换手与背离 − |
| 形态 | 收盘位置 / ATR / 布林带位置 / 均线排列 | mean((c−low)/(high−low))、mean(TR/c)、（c−MA20)/(2σ20)、三条均线条件的计数 | 收盘位置与排列 +，ATR 与上轨 − |

三件与"再算几个指标"不同的处理：

1. **中性化**：先按证监会大类对**分位**去均值（行业成员 <3 时退回全样本均值），再对
   自由流通市值与 beta 的横截面排序做 OLS 取残差。
2. **正交化**：残差再对现有三因子同日分位回归取残差——这一份才是"增量"。
3. **市值怎么来**：没有逐日总股本时用 `成交额 ÷ 换手率` 反推自由流通市值。这条恒等式
   同时说明「成交额/流通市值」与换手率是同一个量，所以没有单独造这个因子（原清单里
   这一项被合并掉了，避免重复计价）。

### 筛选规则：先验 + 多表达平均 + 稳定性

不再用"训练集 IC 最高"选表达（那在 0.02 的 IC 水平上等于抛硬币，上一版就因此选了
`macd_hist` 而验证集是 `macd_slope` 更好）。现在的规则是：

- 先验符号在 `factors.FACTOR_SPECS` 里写死，反号是结论、不是翻转的理由；
- 同族表达按先验对齐后**等权平均**成族综合分，不挑单个表达；
- 族综合分必须同时满足五条才进模型：增量 IC ≥ 0.01、t ≥ 2、半年同号率 ≥ 70%、
  与现有因子相关 < 0.5、年换手 ≤ 8 倍。

### 结果（60 只沪深300 × 3089 个交易日，20 日标签，5 折 purged walk-forward）

| 族 | 增量 IC | t | 半年同号 | 与现有最大相关 | 年换手 | 毛年化 | 净年化 | 判定 |
|---|---|---|---|---|---|---|---|---|
| 反转 | +0.002 | +0.41 | 48% | 0.34 | 9.5× | +1.51% | −0.42% | 未通过 |
| 动量 | +0.009 | +0.78 | 60% | 0.37 | 6.0× | +3.60% | +2.38% | 未通过 |
| 风险 | +0.030 | +3.17 | 76% | 0.11 | 5.5× | +2.61% | +1.51% | 通过 |
| 流动性 | +0.046 | +4.90 | 84% | 0.23 | 5.7× | +4.40% | +3.25% | 通过 |
| 形态 | +0.020 | +2.39 | 60% | 0.09 | 7.8× | +2.75% | +1.16% | 未通过 |

组合模型：现有三因子 OOS IC **+0.030** [+0.005, +0.056]；加入风险与流动性两族后
**+0.048** [+0.024, +0.071]；逐日配对差 **+0.022** [+0.003, +0.038]，t = 2.42。

三个必须讲清楚的地方：

- **反转打不过成本**。族毛年化 +1.51%，年换手 9.5 倍，按单边换手折算成本 1.92pp，净 −0.42%。
  A 股短期反转确实存在，但这个换手频率下拿不到。
- **动量族被平均掉了**。52 周高点单独看增量 IC +0.030、t 2.76，已经够格；但同族的
  12–1、6–1、斜率都是噪声，等权平均后整族只有 +0.009。这是"多表达平均"的代价，
  也正好是"挑训练集 IC 最高"的反面——报告里只把它列为诊断，不据此补进模型。
- **偏度与先验相反**。先验取正（彩票型被高估），实测增量 IC −0.014；反向不等于要翻转符号，
  它说明这份样本里正偏股票反而跑输，值得单独研究。

## 打分链路 v4（`scoring.py` / `score_study.py`）

把旧的硬阈值打分（MACD 柱为正 +9、为负 −8，量比 ≥1.3 才给分……）拆成五个可以分别
验证的环节。`scoring.py` 只做数值与统计，不取数据；`score_study.py` 负责注入面板、
跑十档对照、写报告。

| 环节 | 函数 | 输入 | 输出 |
| --- | --- | --- | --- |
| ① 连续单调变换 | `tanh_score` / `piecewise_score` / `factor_score` | 原始因子值、center、scale、先验方向 | −1..+1，严格单调、有界、导数连续 |
| ② 横截面标准化 + 中性化 | `standardize`（内含 `robust_z` / `industry_demean` / `neutralize`） | 当日横截面原始值、行业、log 市值、beta | 中性化后压到 −1..+1 的分数 |
| ③ 权重收缩 | `build_design` / `fit_ridge` / `bootstrap_fit` / `stability_weights` | 逐日因子分数 + 标签分位 | 系数、同号率、90% 区间、最终权重 |
| ④ 分位校准 | `IsotonicCalibrator`（PAVA + CV 收缩）/ `quantile_fit` / `calibration_curve` | 分数、实际分位、日期 | 分数 → 预期 20 日超额收益分位 |
| ⑤ 验收指标 | `daily_ic` / `quintile_table` / `turnover_series` / `calibration_metrics(_ci)` | 分数、未来收益 | IC 区间、五分组、换手、ECE/斜率 |

关键口径：

- **变换必须单调**。所以 RSI「48–68 才给分」、ret20「涨太多扣分」这两条生产规则被排除在
  电池之外——它们对原始因子非单调，塞进单调变换只会制造错误斜率。
- **中性化顺序**：行业分组去均值 → 市值 + beta 的 OLS 残差 → 重新做 MAD 缩放。
  残差的标准差已经变了，不重缩放等于偷偷改权重。
- **权重是贝叶斯岭**：先验均值取等权（`spread / n`），τ 越小收缩越强。bootstrap 按
  **日块**重抽样（块长 = 标签周期），同号率 < 80% 直接剔除，且方向与先验相反也剔除。
- **校准要再乘 λ**。拟合内的 isotonic 一定比样本外「敢说」，λ 由训练集内部的 5 折
  purged CV 估计（`p = 0.5 + λ·(iso(score) − 0.5)`）；不给日期时退化为 λ=1 并标注。
- **换手对比必须同起点**：基线是同一批 12 因子的三分位阶跃版，两档之间只差变换本身。

## Regime 自适应暴露（`regime.py` / `regime_study.py`）

按"IC 在 risk-off 时失效"的假设做的一套**只调仓位、不换权重**的叠加层。核心是把
regime 识别与组合构建解耦：regime 只管一个 0–1 的暴露系数，因子权重保持不变。

### 结构

```
沪深300 收盘 / MA200 ─┐
20 日已实现波动分位   ├─► 三个票（0.50 / 0.30 / 0.20）─► 慢信号（5 日均）─► 5 日确认
广度（MA20 上方占比） ┘                                        │
距 60 日高点回撤 ≥12% ──────────────► 熔断腿（立刻减仓，恢复仍需确认）
                                                              │
                                       exposure ∈ {1.0, 0.5} ─┴─► 目标权重 × exposure
```

- **分类器是规则，不是模型**：三个阈值（年线、波动分位 80%、广度 40%）全部写死，
  没有任何参数在数据上选过。样本只有 ~120 个独立块，训练分类器等于给 regime 标签本身过拟合。
- **趋势是主腿**（权重 0.50，单独即可触发）。早期版本用 0.40/0.35/0.25 的"三选二"，
  回测发现致命盲区：从高位开始的缓跌里 MA200 没破、波动也没进前 20%，三票凑不齐两票，
  全程 risk_on——2026 年 1–3 月（−13.8%）被完整漏掉。
- **熔断腿是必需的补充**。三票 + 5 日确认在 2015-06 这种"从高位直接崩"的行情里，
  要等主跌段走完才翻面（回撤 −34.9% 几乎没改善）。加一条"距 60 日高点 −12% 立即减仓"
  才把回撤压到 −22.0%，且 10%/12% 两档结果一致（不依赖单一阈值）。
- **不对称的 hysteresis**：出场快（熔断当日）、进场慢（仍要 5 日确认）。对称的 5 日确认
  两边都慢，实测被 2015 和 2026 两次"高位缓跌"击穿。
- `exposure_for_open()` 把收盘确认的状态平移到次日开盘使用，避免偷看当天收盘。

### 结论（59 只个股 2015-01 → 2026-09）

| 项 | 结果 |
| --- | --- |
| 主模型（防御型 6 因子） | 回撤 −34.85% → −22.00%（−37%），年化 29.30% → 23.37%（**−5.93pp**） |
| 同平均仓位的恒定 77% | 22.55% / −27.78%：C12 比它 +0.82pp、少亏 5.8pp（真 timing） |
| 纯动量书 | −49.44% → −32.78%（−34%），年化 13.59% → **15.81%**（+2.22pp） |
| 2018 / 2022 / 2026 | 前两年成立（区间收益 −20.6%→−10.6%、−19.1%→−9.9%），2026 不成立 |
| 切换成本 | 41 次（3.7 次/年）、平均滞后 4 个交易日、累计滞后成本 1.2pp |

**关键判断：这套叠加层对"动量书"有效、对"防御书"只是降杠杆。** 纯动量书在 risk_off
状态的 IC 是 −0.0379 [−0.0767, −0.0039]（显著为负），压暴露同时改善回撤与收益；主模型
在四种状态下 IC 全为正（+0.041~+0.078），压暴露只能按比例缩小收益，换不到"−20% 回撤
+ <1pp 代价"这个组合。所以先确认你的书是不是动量属性，再决定要不要上这层。

**2026 不成立**是真实弱点而非调参问题：当年 1–3 月是缓跌，指数始终在 MA200 上方、波动
分位没进前 20%、熔断要等 −12% 才触发，触发时已经跌完。要覆盖这种形态需要更快的趋势腿
（MA60 下穿）或更浅的熔断，两者都会提高切换频率，是下一步的候选。

## 5 折 purged walk-forward v2（`wfv2.py` / `wfv2_study.py`）

针对"单次 60/40 + 训练集 IC 最大值筛特征 + 无收缩 + 无集成"的四项改进，逐项给指标。

```
EW      等权因子（12 个，先验对齐，不拟合）——免费基线
SINGLE  h=20 + 全因子 + 贝叶斯岭 + 换手惩罚
ENS4    4 个 horizon 的秩平均
ENS     4 horizon + 5 因子族 = 9 成员秩平均
```

| 项 | 做法 | 验收指标 |
| --- | --- | --- |
| 切分 | 折边界按 h=20 划，5 折，purge 20 + embargo 5；更长 horizon 的成员折内再退 `h−20` | 每折 OOS IC、ICIR、正折比例、净净值 |
| 样本权重 | 标签唯一性权重（逐日采样恒为 1/h，故对单 horizon **不改变点估计**）；跨 horizon 合并时按 1/h | 朴素 t vs 块自助 t 的放大倍数 |
| 收缩 | 等权先验贝叶斯岭，τ∈{0.02,0.05,0.15}；`γ‖β−β_prev‖²` 作换手惩罚 | 系数跨折同号率 |
| 集成 | 秩平均 + 主模型分数破并列 | ICIR 是否提升、换手是否不增 |
| 目标函数 | 内层（训练块最后 1/3，带 purge）最大化周期级**净 Sharpe** | 选出的 τ/γ 与旧口径对照 |
| 指标体系 | 合并 IC + 块自助区间、ICIR、正折、净 Sharpe、等权对照 | 严禁用测试折调参 |

### 结论（59 只 × 2830 日，开发段 2344 日，末 2 年锁箱）

| 变体 | 合并 IC | 正折 | ICIR | 换手 | 净年化 | Sharpe | 最大回撤 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| EW | +0.0421 | 5/5 | 0.23 | 1540% | 16.89% | 0.75 | −43.8% |
| SINGLE | +0.0607 | 4/5 | 0.35 | 1577% | 25.20% | 1.00 | −39.2% |
| ENS4 | +0.0616 | 4/5 | 0.36 | 1693% | 21.59% | 0.88 | −38.6% |
| ENS | +0.0584 | 4/5 | 0.34 | 1858% | 22.92% | 0.94 | −38.7% |

- **朴素 t 会把重叠标签放大 3.5 倍**（14.38 → 4.12），任何"t>2 所以显著"都必须换成块自助。
- **折胜率、系数稳定性达标**（11/12 个因子 ≥4/5 折同号）；但 4 个风险类因子（macd / downside / mdd）
  在**所有折都是负号**，与先验相反——收缩能压小、不能纠正，这是"先验错"而不是"估计不稳"。
- **集成没达标**：成员平均秩相关只有 0.38（足够独立），但等权平均把 5 个单因子族成员的偏差也
  平均进来，h 集成 ICIR 仅 +0.01，换手 +116pp；全集成 IC 反而低于单模型。
- **等权因子几乎打平拟合模型**（IC +0.042 vs +0.061、5/5 vs 4/5 正折），说明这套打分的大部分
  信息来自因子集本身，权重贡献有限——这也是为什么第 5 折（2022-10→2024-09）所有变体一起转负。

### 电池剥离实验（3 个反号因子）

macd_hist / downside20 / mdd60 在 5 折中**全部为负号**（与先验同号率 0/5），mom12_1 是 3/5。
四种配置对照（`python wfv2_compare.py base prune3 prune4 flip3`）：

| 配置 | 因子 | 拟合 IC | ICIR | 净 Sharpe | 回撤 | 等权 IC | 等权回撤 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 全电池 | 12 | +0.0607 | 0.35 | 1.00 | −39.2% | +0.0421 | −43.8% |
| 剔除 3 个反号 | 9 | +0.0534 | 0.31 | 0.79 | −43.1% | +0.0483 | −34.4% |
| 剔除 4 个（含 mom12_1） | 8 | +0.0552 | 0.32 | 0.88 | −38.8% | +0.0525 | −31.0% |
| 改先验（3 个翻符号） | 12 | +0.0606 | 0.35 | 0.98 | −38.8% | +0.0465 | −48.8% |

结论：**反号不是噪声，是反向预测力**。拟合模型早就学出了负号（所以 flip 后几乎不变），
剔除等于删掉它已经用上的信息——IC、ICIR、Sharpe 全部下降；只有**等权**书受益于剔除，
因为等权没有负号，只能按错方向硬加权。代价是：全电池在风险维度上是反向暴露
（越高波动越买），IC 赚了，回撤 −39.2% 也放大了。要不要这个暴露是独立的决定，
不是"删因子"能回答的。

## 跨资产 ETF 时间序列配置（`etf_allocation.py`）

针对"个股横截面只有 3.6 个有效 bet"的另一条路：不在 55 只票里排序，而是在 12 只
低相关 ETF 上做"该不该持有"，评价口径换成组合净值。

```
12 腿 + 现金：A股 5（300/500/创业板/1000/科创50）· 债 1 · 黄金 1 · 商品股 1 · 海外 4（纳指/标普/恒生/日经）

入场（四条全满足）  12–1 动量 > 0 · 收盘 > MA60 · 收盘 > MA120 · 距 252 日高点 > −15%
持有（两条）        动量 > 0 · 收盘 > MA120（MA60 只用于入场 → 快进慢出）
权重                ERC（60 日协方差）· 单腿 ≤30% · A股 ≤50% · 海外 ≤50%
风险                组合事前波动 >10% 等比缩放（只降不升）· 未分配买 511880
再平衡              月度 · 单腿变动 <3pp 不动 · 单次单边换手 ≤30% · 成本 7.5bp
```

### 结果（2015-01 → 2026-10，2865 个交易日）

| 方案 | 年化 | 波动 | 净 Sharpe | 最大回撤 | Calmar | 年换手 |
| --- | --- | --- | --- | --- | --- | --- |
| 策略 BASE | 6.78% | 5.27% | **1.29** | **−9.94%** | **0.68** | 146% |
| 等权 ETF | 9.20% | 17.95% | 0.51 | −30.02% | 0.31 | 31% |
| 60/40 | 3.55% | 12.95% | 0.27 | −28.36% | 0.12 | 17% |
| 沪深300 | 3.03% | 22.05% | 0.14 | −45.45% | 0.07 | 4% |

分区间：2018 **+2.84%**（等权 −16.08%）、2022 **−2.79%**（等权 −24.93%）、
2025–26 +7.69%（等权 +31.28%）。同风险等效收益：策略 6.78% vs 等权 2.70%、60/40 1.44%。

三个必须说清的点：

1. **10% 波动目标没有触发**。12 条低相关腿做 ERC 后组合波动天然只有 5.3%，要 1.9× 杠杆
   才到 10%——长-only 不加杠杆上不去。这是分散化的数学，不是参数问题。允许 1.9× 杠杆时
   几何近似年化 ≈13.3%、回撤 ≈−18.9%，扣融资后约 11%–12%。
2. **商品腿是股票代理**（510170 = 上证大宗商品股票指数），与 A 股相关性偏高；真商品工具
   （159980 有色期货 / 159985 豆粕）2019 才有数据，接入后要重跑。
3. **2015 泡沫期落后**（+6.66% vs 等权 +50%）：趋势策略在"无回撤的垂直上涨"里天然进场晚，
   这是为 2018/2022 的保护付的价格。

### 纸面跟踪：先记账，再谈调仓

`latest.json` 只是"该配什么"，不能证明"能不能照着做"。所以每次运行都会往
`reports/etf/paper.jsonl` 追加一条记录（同一 `signal_date + data_version + rule_version` 只记一次），
`paper_summary()` 用**下一个信号日的次日开盘价**结算每一期：

- 买入价 = 信号日之后第一个交易日的开盘价，卖出价 = 下次信号日之后第一个交易日的开盘价；
- 成本 = 买卖两侧分别按 7.5bp 计（与回测同一组常数、同一公式），单边换手 = 0.5×(买+卖)；
- 输出 `avg_cost_bps` 与回测的"平均单次调仓成本"对照，不一致会在页面标红。

页面上的"纸面跟踪"胶囊在记录 < 2 条时直接写"样本不足"，不显示收益率——**观察期 1–3 个月，
期间页面只呈现配置与纸面成本，不作为调仓依据**。

## P2-10 基本面 / 资金流 / 另类数据（`research/datasets/` + `research/fundamentals.py`）

针对"只用 OHLCV 时横截面收益有一大块解释不了"，补五个维度。**数据获取是可插拔的研究层
组件，生产层零改动**：`app.py`/`analyzer.py`/`fields.py` 没有新增一行 import。

### 结构

```
外部源                     规范长表                        因子层
baostock 财报/预告/分红 ┐  {symbol, field, value,          research/fundamentals.py
东财 两融/龙虎榜/北向   ├→   period, available, source} ─→ 派生 TTM → 面板 → 中性化
CSV 分析师/回购/解禁    ┘         ↑ PIT 对齐                    ↑ 增量 IC
                          research/pit_join.AsOfBook      （对 12 因子基线正交化）
```

- **每条记录都带 `period` 与 `available`**。`available` 是该数据"公开可得"的日期：
  财报用 `pubDate`、分红用除权除息日、两融/龙虎榜用 T+1。`validate()` 强制
  `available >= period`，违反直接抛错；只有事件类（业绩预告）豁免，因为预告本来
  就发布在报告期结束之前。
- **重述按"当时能看到的那一版"**：同一 `(标的,报告期)` 有多次披露时，`AsOfBook`
  取 `available <= T` 中最新的一条，不会把 2025 年的追溯调整提前用到 2020 年。
- **过期上限**：财务字段 500 天、事件 120 天。公司停止披露后不沿用三年旧的 ROE。
- **不复权价单独抓**：`.cache/fields` 是后复权价，拿它乘总股本算市值会得到完全错误的 EP/BP。

### 五个维度（17 个因子）

| 维度 | 因子 | 构造 | 先验 |
| --- | --- | --- | --- |
| 价值 | EP / BP / SP / 股息率 | `eps_ttm/price`、`bps/price`、`revenue_ttm/市值`、过去 365 天已实施分红/price | + |
| 质量 | ROE(TTM) / 毛利率 / CFO÷净利润 / 应计 | `np_ttm/equity`、`gp_margin`、`CFOToNP`、`roe_ttm×(1−CFO/NP)` | 前三 +、应计 − |
| 成长 | 营收增速 / 利润增速 / 一致预期修正 | TTM 同比（自拼，不用报表累计值）；修正走 CSV | + |
| 资金 | 融资余额占比 / 融资净买入强度 / 北向持股 / 龙虎榜净买入 | 余额÷流通市值、20 日变化、持股÷流通股本、30 日净买入÷成交额 | 余额占比 −，其余 + |
| 事件 | 业绩预告方向 / 预告超预期 | 类型映射 −1..+1（120 天有效）、预告增速 − 上一期已实现同比 | + |

TTM 用"本期累计 + 上年年报 − 上年同期累计"自拼；净资产用 `net_profit/roe` 还原
（亏损股直接缺失，不用 0 或行业均值填）。

### 中性化与增量 IC

逐日：分位 → 行业去均值（证监会 L1，组内 <3 只退回全样本）→ 规模 + beta 的 OLS 残差 →
再分位 → **对现有 12 因子基线正交化**。两次正交化的顺序不能反：先扣行业/规模，再扣
OHLCV，否则行业效应会被算成"增量"。

指标有三个层次：原始 IC、中性化 IC、**增量 IC**（正交化之后的 IC）。只有增量 IC 的
90% 区间不含 0，才说明这个维度补了 OHLCV 没有的信息。组合增量固定 0.8×基线 + 0.2×增量，
不搜索权重。

### 结果（60 只个股 × 3,089 日，2015-01 → 2026-10）

| 因子 | 中性化 IC | 增量 IC [90%] | 组合 ΔIC |
| --- | --- | --- | --- |
| 融资余额占比 | +0.0533 | **+0.0392 [+0.0124, +0.0673]** | +0.0071 |
| 股息率 | +0.0387 | **+0.0340 [+0.0089, +0.0568]** | +0.0057 |
| 盈利收益率 | +0.0404 | **+0.0328 [+0.0119, +0.0566]** | +0.0060 |
| ROE(TTM) | +0.0273 | **+0.0305 [+0.0109, +0.0512]** | +0.0056 |
| 毛利率 | +0.0357 | +0.0218 [−0.0084, +0.0498] | +0.0036 |
| 融资净买入强度 | −0.0255 | −0.0255 [−0.0420, −0.0086] | −0.0063 |
| 其余 6 个 | — | 区间含 0 | ≈0 |

- **PIT 零越界**（724,586 条），财报披露滞后中位 51 天、P90 108 天、最大 476 天。
- **前视偏差可量化**：同一批因子按"报告期"而非"公告日"对齐，ROE 的 IC 从 +0.0069
  虚增到 +0.0213（3.09×）、EP 从 +0.0165 到 +0.0311（1.88×），全样本中位虚增 +0.0099。
  这就是"财报一出来就有信号"这类结论最常见的来源。
- **融资余额占比是最强的新增维度**：先验为负（拥挤度），翻正后增量 IC +0.039；
  但**融资净买入强度显著为负**，与先验相反——追涨的杠杆资金是反向指标，这一条只能
  当风险信号用，不能当买入信号。
- **事件/北向在 60 只票上不可评估**：龙虎榜平均 4.1 只、业绩预告 15.8 只有值，低于
  横截面下限 30 只。这不是因子无效，是事件数据天然稀疏，需要 300+ 只票的池子。

## 模型边界

三字段是透明的规则模型，不是收益预测。五条独立口径（三字段 + 新因子族 + 跨资产组合）指向同一个分工：**描述分能单调区分波动状态，但对回撤与 VaR 区分力弱（ρ≈−0.2）且半年不稳定；选股分单独用没有可外推的排序能力（锁箱期 IC 区间覆盖 0）；新因子族里的风险与流动性两族能带来 +0.018 的 OOS IC 增量，但增量主要集中在换手率（−0.052）与特质波动（−0.041）这两个朴素维度——本质是"低拥挤 + 低风险"，不是新信息；能通过组合层检验的仍是择时与跨资产配置。** 因此正确的用法是：描述分用来看「现在什么状态」，选股分只作池内相对排序的参考并明确标注「无超额证据」，仓位由 regime 的总暴露上限约束。任何「分数高所以买」的推断都跨了口径。个股分析不包含财务报表质量、估值历史分位、行业景气、新闻事件、停复牌和个人资产状况；ETF 分析不包含跟踪误差、实时溢折价、基金费率、规模变化和底层指数估值。公开数据源可能延迟或中断；如用于生产环境，应替换 `market_data.py` 中的数据层为有授权和 SLA 的供应商，并增加数据校验。

后续所有方向只引用带 95% 区间的 IC、T+1 扣费后的净净值、风格归因后的残差 alpha，以及做过 BH-FDR / 通货紧缩的显著性；不再用单次切分的点估计下结论。

本项目仅供学习与研究，不构成证券投资建议。
